# Sistema de estudiantes

Este proyecto usa MySQL para guardar y consultar estudiantes.

## Antes de ejecutarlo

1. Crea la base de datos `estudiantes` y la tabla `estudiantes2026`.
2. Configura las variables de entorno `DB_USER` y `DB_PASSWORD` en tu sistema.
   `DB_USER` puede ser `root`; `DB_PASSWORD` debe ser la contraseña de MySQL.
3. Reinicia VS Code para que tome las variables y ejecuta `UTN.Main` o
   `UTN.presentacion.SistemaEstudiantesApp`.

No escribas tu contraseña en el código ni la subas al repositorio.
