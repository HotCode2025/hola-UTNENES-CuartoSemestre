## Agregar personajes

Los personajes se encuentran en el array `personajes` y son instancias de la clase `Personaje`.
Para agregar uno nuevo desde JavaScript:

```js
agregarPersonaje("Iroh", "Fuego", "🔥", "./img/iroh.jpg");
mostrarPersonajes();
```

Cada personaje puede atacar mediante su método `atacar(ataque)`.
