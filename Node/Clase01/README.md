# Clase 1: Introducción a Node.js

En esta primera clase instalamos Node.js y conocimos sus características principales.

## ¿Qué es Node.js?

Node.js permite ejecutar JavaScript fuera del navegador, por ejemplo, en un servidor. Está construido sobre V8, el motor de JavaScript creado por Google y escrito en C++.

Node.js trabaja con eventos y con operaciones de entrada y salida que no bloquean el resto del programa (*non-blocking I/O*). Esto ayuda a crear aplicaciones rápidas y eficientes.

## ¿Qué podemos hacer con Node.js?

- Crear servidores locales o remotos.
- Desarrollar servicios REST.
- Conectarnos con bases de datos.
- Manejar archivos con el módulo `File System`.
- Usar sockets para comunicar cliente y servidor, por ejemplo, en un chat.

## ¿Por qué es tan popular?

Node.js es rápido y relativamente fácil de aprender, sobre todo si ya conocemos JavaScript. Además, cuenta con muchos paquetes que podemos incorporar a nuestros proyectos mediante npm, su ecosistema de herramientas y librerías.

## ¿Quiénes lo utilizan?

Empresas como Netflix, PayPal, LinkedIn, Walmart, NASA, eBay y Uber utilizan Node.js en distintos proyectos y servicios.
